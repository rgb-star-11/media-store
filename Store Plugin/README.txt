پلاگین اختصاصی گالری، فروش و نمایش آثار عکاسی و ویدیو فوتیج با رابط کاربری React 19.

== Description ==

پلاگین Studio Media Store یک افزونه کامل و خودکفا برای وردپرس است که به شما امکان می‌دهد سیستم گالری عکاسی و فروش ویدیو فوتیج‌های اختصاصی را تنها با یک شورت‌کد ساده در وردپرس راه‌اندازی کنید.

امکانات برجسته:
* رابط کاربری فوق‌العاده سریع و حرفه‌ای با React 19
* اسلایدشو هیرو بدون پرش با فیلتر هوشمند عکس‌های افقی
* سیستم پیش‌نمایش ویدیو فوتیج‌ها و دانلود فایل‌های اختصاصی
* ثبت‌نام پیامکی و رمز عبور به همراه بازیابی رمز با ایمیل
* پنل مدیریت اختصاصی و سفارشی‌سازی متون و افکت‌های نوری

== Installation ==

۱. پوشه `Store Plugin` را به `wp-content/plugins/` در هاست یا وردپرس خود منتقل کنید (یا آن را به صورت zip آپلود نمایید).
۲. وارد پنل مدیریت وردپرس شوید و از بخش "افزونه‌ها"، افزونه **Studio Media Store** را فعال کنید.
۳. یک برگه جدید ایجاد کرده و شورت‌کد زیر را درون آن قرار دهید:

`[studio_media_store]`

۴. برگه را منتشر کنید. گالری و فروشگاه شما آماده استفاده است!
